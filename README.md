
# My Personal Portfolio

## Description
A simple, responsive personal portfolio website built from scratch
using HTML5, CSS3, and JavaScript ES6+.

## Features
- Navigation bar
- About Me section with profile photo
- Skills grid
- Four projects (Project 00–03)
- Hobbies section
- Contact form
- Dark and light theme switcher
- Responsive mobile layout

## Technologies
- HTML5
- CSS3 (Flexbox and media queries)
- JavaScript ES6+
- Git

## How to Run
1. Download or clone this project.
2. Open index.html in your browser.
3. Add your photo to assets/profile.jpg.

## JavaScript Event Lifecycle
1. User clicks the theme button.
2. The browser fires a click event.
3. The JavaScript callback runs.
4. classList.toggle("dark") changes the body's CSS class.
5. CSS applies the dark theme.
6. The button text changes to "Light Mode" or "Dark Mode".
